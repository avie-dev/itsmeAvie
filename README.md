# itsmeAvie

A personal "about me" page for Jonavil (Avie) Fukai: Project Manager, PMP, Women Techmakers Ambassador and community builder in Chiba, Japan.

It's a plain static site (`index.html` + `styles.css`) with no build step. Open `index.html` in a browser to view it, or publish it with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
